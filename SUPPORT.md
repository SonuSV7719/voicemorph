# Support

Thanks for using VoiceMorph. Here's how to get help.

## Before asking

1. Check the [documentation](./docs) — especially the
   [FAQ](./docs/FAQ.md), [Configuration](./docs/CONFIGURATION.md), and
   [Development](./docs/DEVELOPMENT.md) guides.
2. Search [existing issues](https://github.com/SonuSV7719/voicemorph/issues).

## Ways to get help

| Channel | Use it for |
|---|---|
| [GitHub Discussions](https://github.com/SonuSV7719/voicemorph/discussions) | Questions, ideas, show-and-tell |
| [GitHub Issues](https://github.com/SonuSV7719/voicemorph/issues) | Reproducible bugs and concrete feature requests |
| [Security advisory](./SECURITY.md) | Vulnerabilities (private) |

## Filing a good bug report

Include:

- What you expected vs. what happened.
- Component: engine / media / backend / desktop / mobile.
- Environment: OS, Python version, Node version, GPU (if any), commit/tag.
- Exact commands and minimal steps to reproduce.
- Relevant logs (scrub secrets and personal data first).

The issue templates will prompt you for these.

## What's out of scope

- Help obtaining or cloning a voice you don't have the right to use — see
  [`docs/ETHICS.md`](./docs/ETHICS.md).
- General ML/PyTorch/CUDA setup unrelated to VoiceMorph.
